# Key bindings of ASCII mode (go run -tags development . ascii). Same keys as the tile UI where a terminal allows.
# Format: key -> command. Keys: a letter or symbol, Space, Enter, Tab, Backtab, Esc, Up/Down/Left/Right, F1-F12, Ctrl+x.
