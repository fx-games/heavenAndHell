== Multi-Shot (Sustained)
Scale Shot count with skill level (2-6)
While active, all ranged attacks/skills will shoot multiple arrows,
but cannot be aimed individually.
The mana cost is increased when using other skills
and multiplied by the number of arrows fired.

== Arrow Rain
Scale area of effect with skill level (3x3 - 5x5)
Hits random targets in the area of effect.
Guaranteed to hit all immobile targets.

== Trick Shot
Scale penetration count with skill level (2-Inf.)
Scale bounce count with skill level (2-6)

One Arrow will penetrate all enemies in a line,
bounce off any walls, and penetrate all enemies in a line again.

== Debilitating Shot (Untargeted, One-off)
Scale duration with skill level (2-6)
Chance to inflict stunned/slowed/confusion/rage/blinded/damage over time
Will always cause immobilized when used against an enemy adjacent to a wall.
Doesn't spend a whole turn. Very quick action.

Your next ranged attack/skill will cause a debuff.

== Man Stopper
Scale knockback distance with skill level (1-5)
Knockback any enemy hit.
Enemies colliding with walls take more damage.

== Jumpstart
Scale jump distance with skill level (1-5)
Requires:
 - Player has moved towards enemy and is now adjacent to him
 - There is free space behind the enemy

Jump over the enemy and shoot him in the back for increased damage.
If you start the jump adjacent to a wall, the enemy will be pushed into that position.
