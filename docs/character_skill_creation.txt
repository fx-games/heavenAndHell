Adding a skill to a class.

The skill needs to be added to the skill list of the specified class.
The location of the file to do this is relative to the root folder of the project.

assets/data/classes.rec

Skill types are defined in two ways
untargeted_skill:
targeted_skill:

Then named in the same fashion these are internal names
heal_health
fire_wall

The targeted Effect then needs to be defined
The path is relative to the projects root folder

assets/data/effects/targeted.rec
assets/data/effects/untargeted.rec

This is the structure that is used

name:
internal_name:
icon:
dlvl:
targeting:
hit_zone:
effect:

Name
is what will be seen or used/repesented in the game as a string so capitols and spaces are used
e.g. Fire Wall,  Heal Self

internal_name
is used for code purposes so easy to understand and use
e.g. fire_wall, heal_self
