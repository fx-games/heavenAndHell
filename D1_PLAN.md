# Diablo 1 turn-based rebuild — plan

Goal: play through the complete Diablo 1 game as a turn-based variant.
From D1: loot, enemies, dungeon generation. Kept from H&H: graphics, UI, time management.

## Decisions

1. **World structure: D1 replaces H&H.** Tristram + 16 levels (Cathedral 1–4, Catacombs 5–8, Caves 9–12, Hell 13–16), Diablo on 16. H&H story (Meat Jack, Zedek, Lucifer, hell town, 12-level layout) is removed.
2. **Quests: critical path + boss quests.**
   - Critical: Archbishop Lazarus (15, own level) → Diablo (16).
   - Boss: The Butcher (2), Skeleton King Leoric (3, own level), Zhar the Mad (8), Warlord of Blood (13).
3. **Dungeon gen: port D1 layout algorithms (L1–L4) down to the floor/wall/door grid.** Fill `dungen.DungeonMap`, render with existing tilemaps. Skip isometric tile-fix/shadow/dirt passes. 1 D1 cell → 2×2 cells (80×80 levels). Set pieces (Leoric, Lazarus, Warlord, Diablo) hand-rebuilt as LDtk templates (`.DUN` files live in the MPQ, not the source). Go `math/rand`, not D1's RNG.
4. **Combat: D1 formulas inside H&H's turn/energy system.** D1 to-hit (Dex/clvl/item to-hit vs AC), D1 damage (weapon min–max + Str/level bonus + dmg% affixes), damage types physical/fire/lightning/magic, monster resist/immunity from `xl_monst`, player resists capped 75%, shield block chance. Attack-speed affixes → action time cost. H&H armor-as-reduction, armor penetration, weapon quality factor removed.
5. **Character: D1 sheet.** Warrior/Rogue/Sorcerer with D1 starting stats, gear, stat caps. Str/Mag/Dex/Vit. D1 XP table to clvl 50, 5 points/level, D1 per-class HP/mana growth. Item Str/Mag/Dex requirements enforced. H&H classes, class skills, Int removed.
6. **Spells: all 26 SP spells with D1 spell levels.** Books raise spell level; D1 per-level damage/mana; scrolls & staves (charges) cast at D1 levels. Turn-based: missiles resolve instantly along a line (`fire_bresen` pattern); AoE/chain instant; Fire Wall/Flame Wave/Guardian/Golem are per-turn actors/objects in the energy system; Mana Shield/Infravision/Stone Curse are status effects; Town Portal = two-way town transition (replaces `recall`). Excluded: monster-only/unused, class skills, MP-only (Resurrect, Heal Other). Unused H&H effects deleted unless monsters need them.
7. **Monster AI: one Go function per D1 AI type (24),** built on H&H primitives (Dijkstra toward/away, melee, ranged via Q6 missiles, status effects). Per-monster stats from `xl_monst`; speed → action time cost. H&H's 10%-skill-roll AI and rec-defined enemy skills removed.
8. **Sprites: one sheet icon per D1 graphic family (34), variants by tint.** Uniques = base icon, gold tint. Items: one icon per D1 item class (~30), tint by quality (white/blue/gold). Two small mapping tables (family→icon, item class→icon); first-guess icons, user corrects. ASCII mode likewise.
9. **Durability & identification, D1-style.** Weapons lose durability on hit, armor when hit; 0 = broken (no effect) until repaired at Griswold (existing SetToMax). Durability affixes real. Magic/unique items drop unidentified (base name, blue/gold); identify via Cain (free), Identify scroll or spell; unidentified items still work with hidden effects.
10. **Town: keep H&H Town map, swap in D1 NPCs.** Griswold (replaces Shekel + Abel: basic + premium stock, repair), Adria (replaces Kirioth: witch stock, staff recharge), Pepin (replaces Mary: free full heal on talk, healer stock), add Cain (identify) and Wirt (1 premium item, 50 gold to look). D1 store generation (`stores.cpp`, clvl-scaled, restock on return from dungeon), D1 buy/sell prices and buy rules. Town entrances → levels 5/9/13, unlocked once reached; cathedral stairs → level 1. `TownHell` removed.
11. **Saving: one D1-style slot + permadeath option.** Autosave on every level change and on quit. Start menu: Continue / New game (class choice + permadeath toggle). Death: Load last save / New game; with permadeath the save is deleted. Save = small snapshot (player sheet, inventory/equipment, quest flags, spell levels, per-level seed + killed monsters + changed items/objects), levels rebuilt from seed. Riskiest plumbing → build early.
12. **Dungeon objects on `BumpObject`.** Containers with D1 drop rules: chests (S/M/L), sarcophagi, barrels (exploding = fire AoE), bookcases (scrolls/books), weapon & armor racks, decapitated bodies. D1 single-player shrines (26 types, SP subset) with D1 effects + level ranges. Fountains & cauldron with D1 effects. Placement per D1 `InitObjects`. Doors stay H&H doors.
13. **Speeds from D1 frame counts, rounded to tiers.** Monster move speed from walk frames×rate, attack speed from attack frames, relative to player baseline. Tiers: slow ×0.5 / normal ×1 / fast ×1.5 / very fast ×2 (one tunable table in data). Player attack speed from D1 class×weapon frames (`PlrGFXAnimLens`); attack-speed affixes step up a tier.
14. **Data: D1 TSV tables verbatim in `files/assets/data/d1/`, parsed with `encoding/csv` (tab).** `xl_monst`, `xl_umon`, `xl_item`, `xl_uitem`, `xl_ipre`, `xl_isuf`, `xl_spell`, `xl_obj` (+ `xl_quest` for reference). Enum names → Go constants via `map[string]`. H&H enemy/item/effect/class rec files + loaders removed (`recfile` stays for config). Non-table values (formulas, class stats, speed tiers, icon mapping) in Go or one small rec file.
15. **Critical path, D1 sequence with one shortcut.** Staff of Lazarus on a stand on level 15 → bump Cain while carrying it (one fixed text line, sets flag, removes staff; no dialogue system) → red portal (transition object) on 15 → Lazarus set level (LDtk) → Lazarus death spawns return portal + opens stairs down on 15 → level 16 Diablo set piece with its 4 levers (BumpObjects opening wall sections; exception to "levers deferred") → Diablo death → existing end screen (`endMessage.txt`, reworded), save marked completed. Other boss quests have no triggers: boss sits in its set piece; Leoric's level via a marked staircase on 3.
16. **Done = smoke test + debug run + real run.** `go run . playthrough` (next to `dun_gen`/`loot`), for several seeds: generate town, levels 1–16 + set levels; D1 tables load; stairs up/down reachable (existing pathfinding); quest bosses spawn; level-16 levers make Diablo reachable; loot + store stock are valid D1 items; Lazarus → portal → stairs → Diablo flags step through; fail loudly. Debug menu: go to level N, god mode, gold/XP, set quest flags. Done when smoke test passes + one debug run town → Diablo death → end screen + one honest normal run through the Cathedral.
17. **Build order: Cathedral slice first, then widen.** Branch `d1-rebuild`, one commit per milestone, `playthrough` grows each milestone.

## Milestones

1. [x] **Cathedral slice** — D1 table loading, character sheet, D1 combat, L1 generator, levels 1–4 with D1 monsters + AIs, loot drops (affixes, uniques), speed tiers, sprite mapping; `playthrough` for 1–4.
   Notes: sprite icons/tints are first guesses (`common/d1_monster.go`, `common/d1_item.go`). Old H&H content still feeds town shops and levels 5+, so its deletion moved to milestones 3 and 6. Shortcuts are marked `ponytail:` in code.
2. [x] **Saving** — snapshot save, Continue/New game, permadeath toggle, load on death.
   Notes: `savegame.json` in the working directory (`game/save.go`); levels rebuild from `levelSeed` + `LevelSnapshot`. Not saved: explored map/fog, monster AI state, corpses, non-D1 (old H&H) items — revisit when those matter.
3. [x] **Town** — Griswold, Adria, Pepin, Cain, Wirt; D1 store gen; identify, durability, repair; town entrances unlock; delete H&H items/vendor defs.
   Notes: the H&H NPCs are renamed in code (`game/town_d1.go`), Abel's spot became Cain, Wirt stands near the cathedral entrance. Griswold's premium items share his BUY list. Deliberate differences from D1 (per decisions 9/10): Cain identifies for free, broken items stay until repaired. H&H's town stash is gone (D1 has none). The Hell gate (level 13) comes with milestone 6.
4. [x] **Objects** — containers, shrines, fountains.
   Notes: `d1/objects.go` ports InitThemes/InitObjects/CreateThemeRooms (Cathedral theme rooms only; L2–L4 themes come with milestone 6); `common/d1_object.go` operates them. Fixing theme-room detection also corrected the Cathedral grid (it was one cell off D1's walls). Operating an object takes no time, like H&H bump objects. Broken barrels leave walkable debris. Mana Shield/Nova shrines and the Murky Pool's infravision do nothing yet (milestone 5). Any wall counts as a "trap wall", so shrines/bookcases on left walls are rare. Object icons are first guesses.
5. [x] **Spells** — all 26, books/scrolls/staves.
   Notes: formulas in `d1/spells.go`, effects in `common/d1_spell.go`. Press `e` for the spell menu; known spells also sit in the skill bar. Each cast resolves at once on the grid: bolts fly until they hit (a miss flies on), Lightning/Chain/Nova/Flame Wave are rays, Flash/Inferno/fire walls roll D1's per-tick hits in one go, Fire Wall and Guardian are timed objects. Charged Bolts wander on the grid instead of D1's sub-tile paths. Golem: an ally monster; monsters attack whichever of player and golem is closer; it vanishes on level change. Town Portal: one portal, placed next to the town spawn, closed by walking back through it; saved. Mana Shield ends on level change. Staves cast from the pack (D1 needs them in hand). Book requirements don't rise with spell level (that isn't in this D1 source). Monster spellcasters come with milestone 6. Fixed on the way: skeletons from sarcophagi never acted; H&H's ClearQueuedActions crashed on map change.
6. [x] **Catacombs, Caves, Hell** — L2–L4 generators, remaining AIs, levels 1–16; delete H&H enemies/effects/story generator.
   Notes: `d1/drlg_l2.go`–`drlg_l4.go` port the generators, `d1/drlg.go` holds what gendung.cpp shares (transval flood, minisets, `DRLG_PlaceThemeRooms`); `go run . dun_gen <dlvl> [seed]` prints a level. Grid conversion per type: Catacomb walls are whole megatiles (2 cells thick, D1 walls its rooms on all sides); Cave cells are the corners of D1's floor map; Hell works like the Cathedral (floor from L4dungeon, walls on megatile edges from AddWall and theme rooms). L4's 150 tile-fix rules were transcribed by script. Skipped because they don't change what's walkable: catacomb arches/rubble, cave islands and cracks, hell shadows/floor variants (cave lava and fences followed in milestone 7). D1's hall walk can bounce off a room corner forever; after 2000 steps the level is regenerated. Stairs sit next to where D1 puts the player. Levels 5, 9 and 13 have D1's town warp; the town got a Hell gate (`to_hell`). Level 16 has no stairs down and 15 plain stairs until milestone 7.
   Monster AIs: all single-player types except the quest bosses' (milestone 7). `AI_FIREMAN` isn't ported: Incinerators are unavailable in single player. Monster missiles (`common/d1_mmissile.go`) port PlayerMHit (magic to-hit, resistances, block, 1 HP minimum per tick) and resolve at once like the player's spells; flames and acid puddles linger as hazards; charges (horned demons, glooms, snakes) rush along the line and knock back. Like D1, monster missiles only hurt the player, not the golem. Simplifications: circling AIs treat D1's same-room check as always true, monsters don't open doors while circling (MonstCheckDoors), charged bolts fly straight, gargoyles heal one step per turn.
   Removed: H&H level generator (`dungen`), level templates and TownHell from `maps.ldtk`, enemy/effect rec files and their factories, dialogue, story mode/quest log, Lucifer/hell-town code (~16k lines, mostly level templates). Fixed on the way: save/load could lose a monster whose saved cell was still taken.
7. [x] **Quests & ending** — set pieces (Butcher, Leoric, Zhar, Warlord, Lazarus, Diablo), critical-path triggers, end screen, debug shortcuts, full `playthrough`.
   Quest log (D1's questlog): bring back the journal window and its `r` key (removed with H&H's story in milestone 6, old version in commit `6b98f74`), listing the quests above by their D1 name as active or done, with at most a one-line description (no dialogue system, decision 15).
   Notes: `common/d1_quest.go` holds the quest flags, the quest log (`r`), boss placement and `UpdateD1Quests`, which opens whatever the flags unlock each time a level is entered or a flag changes. Set levels are generated instead of LDtk templates: King Leoric's Tomb (`!gen_leoric_3`, a Cathedral level behind extra stairs on 3) and Lazarus' Lair (`!gen_lazarus_15`, a Hell level behind the red portal); both use their parent level's depth for monsters and loot. The Staff of Lazarus lies on a stand on 15; bumping Cain while carrying it opens the red portal. Level 16 stands in for D1's diab1-4 set pieces: Diablo waits in a walled 3×3 chamber that opens once all four levers (one per quarter of the level) are pulled. The Butcher, Zhar and the Warlord stand at random spots, without their D1 rooms. Boss AIs: the Skeleton King raises skeletons, Zhar and Lazarus fight like counselors, Red Vex and Black Jade like succubi, the Warlord like a skeleton, Diablo casts Apocalypse; their talk before the fight is skipped. Diablo's death shows the reworded `endMessage.txt`; the quest flag goes into the next autosave. Debug menu: go to level (including set levels), god mode, complete quest.
   Terrain: tiles already had separate walkable and transparent flags. Cave lava lakes, rivers (each with a bridge) and wooden fences (with a gap or gate) now use them (`CellLava`, `CellFence`), and the monsters' line check sees over them. Cave levels where crossing rivers or fences cut off the stairs are regenerated. Lava (159) and fence (63) icons are first guesses.
   Deviations from the decisions:
   - Decision 3/15: set levels and set pieces are generated from code, not LDtk templates. Lazarus' Lair is a Hell level (D1's is Cathedral-type); Leoric's tomb and the lair are random layouts, not D1's maps.
   - Decision 15: level 16 has one walled chamber that opens when all four levers are pulled, not D1's four quadrant set pieces with levers opening wall sections one by one. The red portal and the staff stand sit at random open spots, without D1's altar and candles.
   - Decision 15: "save marked completed" is only the Diablo quest flag, saved with the next autosave; the end screen is a text window and the game carries on behind it.
   - Decision 2: the Butcher, Zhar and the Warlord stand at random spots without their rooms (Butcher's room, Zhar's library, Warlord's set piece); Zhar doesn't need a library to appear. Boss talk (Zhar, Lazarus, Warlord) is skipped.
   - Decision 7: Leoric's, Zhar's, Lazarus' and the Warlord's AIs are ported without their talk states; Red Vex and Black Jade fight like succubi straight away.
   - Milestone 6 terrain: cave islands, cracks and the Hall of Heroes fix are still skipped (they need the grid built from megatiles, not the floor map).

## Defaults (not grilled)

- Hellfire content, multiplayer-only items/spells/shrines, and difficulty levels (Nightmare/Hell) out of scope.
- UI stays: H&H stack inventory, hotkeys, menus; no D1 grid inventory, belt, automap.
- Unrelated H&H subsystems (`osr`, `console` ASCII mode, `creator`, window-client IPC) left untouched.
